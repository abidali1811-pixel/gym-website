# IronPulse Fitness — Simple Gym Website

A single-page static gym website with responsive layout, dark theme, and sections for hero, about, classes, pricing, and contact.

## Run locally

Open `index.html` in your browser, or serve the folder with any static server:

```bash
# Python 3
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Structure

- `index.html` — page content
- `css/styles.css` — styles
- `js/main.js` — mobile menu, footer year, demo contact form

Customize the gym name, prices, and contact details in `index.html`.
